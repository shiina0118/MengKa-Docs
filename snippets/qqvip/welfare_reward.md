## 福利签到奖励（WelfareReward） {#welfare-reward}

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `type` | number | 奖励类型：`0` 无奖励、`1` 成长值、`2` Q 币、`3` 等级加速、`4` 会员天数 |
| `amount` | number | 奖励数量；含义与单位依奖励类型而定，不统一解释为成长值 |
| `name` | string | 奖励名称 |
| `icon_url` | string | 奖励图标地址 |

奖励对象存在时，`type`、`amount` 始终返回，未提供时为 `0`；`name`、`icon_url` 始终返回，未提供时为空字符串。

查询结果中的奖励用于展示；是否实际发放须结合签到结果判断。奖励类型可能扩展，不要把未知类型当作成长值。
